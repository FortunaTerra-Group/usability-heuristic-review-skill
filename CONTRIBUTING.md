# Contributing

The skill is deliberately short. A proposed change to the procedure needs one thing: a real usability defect that a report in this format left unnamed, stated as the surface, what the user met, and the heuristic that should have caught it. Wording improvements that do not change what the procedure catches are welcome as plain PRs.

Do not add tooling, screenshot pipelines, or enforcement scripts here. This repository is the procedure; the capture and the fix belong to whoever owns the surface.
